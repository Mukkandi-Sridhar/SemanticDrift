# Security Policy

## Supported Versions

This repository holds research code and data. Only the latest version on `main` is maintained.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

The experiment harness reads API keys from a local `.env` file, which is git-ignored, and
redacts keys from anything it logs. Please never commit keys or paste them into issues.

## Reporting a Vulnerability

If you find a security problem in the code or data, please report it by email rather than in a public issue.

**Do not report security vulnerabilities through public GitHub issues.**

Please send an email to: [sridharraoyalls@gmail.com](mailto:sridharraoyalls@gmail.com)

We will endeavor to respond to your report within 48 hours and provide updates as the issue is investigated and resolved.

## Responsible Disclosure
We ask that you follow responsible disclosure guidelines and give us time to investigate and patch the vulnerability before disclosing it publicly.
